A First Semester Project

The Project is a Machine Learning Model YOLO_v8 Fine tuned of a Dataset Containing
Dry Waste
Wet Waste
Electronic Waste
Sanitary Waste

The Machine Learning Model opens the camera and User shows a waste object
Later the Model Tell what Kind of waste it is and correct way to dispose

Like - It's a Wet, Dry, Electronic or Sanitary

If it's Electronic it will locate the nearest E-Waste Centre. (This feature will be added Soon)
